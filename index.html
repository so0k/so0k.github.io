Workshops

Hands-on workshops you can follow at your own pace, each one built around a single running example.

  • TerraConstructs AWS workshop

    Define AWS infrastructure in TypeScript with TerraConstructs and deploy it with Terraform. You build a Lambda function behind API Gateway, write your own reusable construct, and use one from a construct library.

    TerraConstructs · CDKTN · Terraform · AWS · TypeScript

  • Build a docs Skill for Teleport

    A nine lesson brown-bag for platform engineers that turns the Teleport docs into a Claude Agent Skill with an offline BM25 search index, and proves it works with evals. It ends with an honest look at when a skill beats an MCP server.

    Agent Skills · Teleport · BM25 · evals · source on GitHub

  • New Agent in a Box: sandboxing AI coding agents with Strands Box

    A step by step workshop on the Strands Box CLI. You write a profile, add Cedar policies checked by Dogwood, set egress rules, and see what an MCP "code mode" execute tool means for a security officer who wants allow and deny control per API operation.

    Strands Box · Cedar · Dogwood · egress · MCP
